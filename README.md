# LÜ — Adaptive Language Learning MVP

Primera versión experimental de una aplicación que compara estrategias de aprendizaje y adapta progresivamente el entrenamiento según el desempeño del usuario.

## MVP actual

- Español → Inglés
- Estrategias: Contexto, Audio y Recuperación
- 5 palabras por estrategia para prototipo
- Evaluación inmediata
- Comparación inicial de desempeño
- Pantalla de resultados
- Arquitectura preparada para incorporar retención a 24 h y 7 días

## Ejecutar

```bash
npm install
npx expo start
```

Luego abre el proyecto con Expo Go en el celular o con un emulador.
